01 · install

Four steps to shipped

Copy three files, add GSAP, call one function. That's the whole ceremony.

  1. 1

    Copy the library into your project

    Three files are the whole library. The showcase site files stay behind.

    my-site/ ├─ index.html └─ ui/ ├─ tokens.css colors, type, shape, motion ├─ components.css every .y-* class ├─ components.js behaviours + yeet.init() └─ search.js only if you use ⌘K search
  2. 2

    Add GSAP and the fonts

    GSAP powers the motion. The fonts are optional but they're the whole vibe.

    terminal
    npm i gsap
    <head>
    <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wght@12..96,600;12..96,800&family=JetBrains+Mono:wght@500;700&family=Space+Grotesk:wght@500;600;700&display=swap" />
<link rel="stylesheet" href="/ui/tokens.css" />
<link rel="stylesheet" href="/ui/components.css" />
  3. 3

    Wake the components up

    One call wires up tabs, accordions, modals, toasts, tilt, magnetic, marquee and the navbar.

    main.js
    import { yeet } from "./ui/components.js";

yeet.init();
// optional: global ⌘K search
yeet.search({ items: [{ title: "Pricing", href: "#pricing", emoji: "💸" }] });
  4. 4

    Drop in markup. Ship it.

    Grab any snippet from the docs. This one's live, go on, press it.

    index.html
    <button class="y-btn y-btn--pink"
  data-toast="Shipped! 🚀"
  data-toast-bg="var(--y-lime)">
  Ship it
</button>

03 · recipes

Works with whatever

It's just classes and one init call, so it slots into any stack.

index.html
<script type="module">
  import { yeet } from "/ui/components.js";
  yeet.init();
</script>
App.jsx
import { useEffect, useRef } from "react";
import { yeet } from "./ui/components.js";

export default function App() {
  const root = useRef(null);
  // init after render, scoped to this tree
  useEffect(() => { yeet.init(root.current); }, []);
  return (
    <main ref={root}>
      <button className="y-btn y-btn--pink" data-toast="hi from react">Toast</button>
    </main>
  );
}
App.vue
<script setup>
import { onMounted, ref } from "vue";
import { yeet } from "./ui/components.js";
const root = ref(null);
onMounted(() => yeet.init(root.value));
</script>

<template>
  <main ref="root"><button class="y-btn">Vue but loud</button></main>
</template>
Layout.astro
---
import "../ui/tokens.css";
import "../ui/components.css";
---
<slot />
<script>
  import { yeet } from "../ui/components.js";
  yeet.init();
</script>
04 · house rules

Do this, not that

✅Override tokens, not components

Change --y-lime once instead of restyling every button.

🚫Stack 5 accent colors in one view

Pick one hero accent plus one pop. Loud ≠ chaotic.

✅Keep the ink outlines

The 2.5px border + hard shadow is the signature. Thinner is fine, none is not.

🚫Animate everything at once

Motion should guide. Let one thing pop per moment.

✅Respect reduced motion

It's built in. Don't add animations that ignore it.

🚫Put grey text on lime

Use ink on bright colors. Contrast is part of the vibe.
